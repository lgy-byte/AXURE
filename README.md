# AXURE

上海交通大学人工智能研究院 - 弥渡AI医疗大模型项目
项目简介：
⚫ 医疗大模型定制化：参与基于Qwen模型架构，运用 LoRA 低秩自适应微调技术的AI+医疗-弥渡医疗共同体大模型项目，该项目旨在显著提升模型对病历
中非结构化数据的理解与解析能力，精准实现疾病、药物、症状等实体的识别及分析，有效整合碎片化医疗数据； 
⚫ 设计用户交互逻辑：医生在 HIS 系统填写并保存患者信息后，模型立即自动进行智能分析，快速生成可能疾病的疑似诊断结果及对应概率；用xmind设计体
检预问诊系统交互逻辑并用drawio绘制流程图，axure，Figma设计产品原型；设计与医生端的协同机制，实现高优先级咨询（紧急症状、慢性病急性发作）
的自动标记功能，有效推动医患高效衔接，提升整体医疗服务响应速度。 
⚫ 智能医疗客服体系：用axure设计24 小时医疗客服助手产品原型，主导医疗问答知识库的规划，通过8k条高质量数据neo4j构建医疗知识图谱明确覆盖
疾病咨询、就医流程、用药查询等核心内容，成功分流重复性需求。 

AI 医疗大模型产品原型  弥渡AI辅助诊断系统（具体功能包括疑似诊断，本土名医，智能医疗客服体系等功能）
